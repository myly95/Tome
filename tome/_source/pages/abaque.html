Écrire une formule

Une formule commence toujours par =. Exemples :

  • =A2+B2 additionne deux cellules.
  • =SOMME(C2:C30) additionne une plage. On peut aussi écrire les noms anglais : =SUM(C2:C30).
  • =MOYENNE(C2:C30), =MAX(...), =ECARTYPE(...), =NB.SI(C2:C30;">=10")
  • =SI(C2>=10;"Admis";"Ajourné")

Séparez les arguments par ; (ou ,). Dans une formule, les nombres décimaux s'écrivent avec un point : =A2*1.5. Dans une cellule simple, la virgule fonctionne : 12,5.

Le signe $ bloque une référence lors de la recopie : =$B$1*A2. Pour recopier une formule, tirez le petit carré en bas à droite de la sélection, ou utilisez Ctrl D.

Pendant la saisie d'une formule, cliquez sur une cellule pour insérer sa référence.

Pour les statistiques Mesure : écrivez le nom de chaque variable en ligne 1 et les données en dessous, une colonne par variable.
