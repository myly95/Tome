Bibliothèques

Les bibliothèques s'installent automatiquement au premier import. Vous pouvez aussi écrire %pip install nom dans une cellule. Cliquez sur un nom pour le préparer à l'installation.

Tous les paquets en pur Python de PyPI s'installent. Les paquets compilés doivent exister en version WebAssembly : c'est le cas de plus de 300 d'entre eux. PyTorch et TensorFlow ne sont pas disponibles dans le navigateur.

Les paquets CRAN s'installent automatiquement avec library(nom) ou install.packages("nom").

Se connecter avec un jeton d'accès

Créez un jeton « fine-grained » sur github.com, dans Settings, Developer settings, Personal access tokens. Limitez-le aux dépôts voulus avec l'autorisation « Contents : Read and write ». Le jeton reste sur cet appareil et n'est envoyé qu'à GitHub.
