Toutes les écoles d'Haïti, en un clic

Importe les écoles, lycées et universités d'Haïti connus d'OpenStreetMap (données ouvertes, © les contributeurs OpenStreetMap), classés par département. Cela peut prendre une ou deux minutes. Les doublons sont ignorés : vous pouvez relancer plus tard pour récupérer les nouvelles écoles. La liste n'est pas parfaite : complétez-la ensuite avec votre propre fichier.

Importez un fichier CSV ou Excel avec les colonnes nom, commune, departement et, si vous l'avez, type (public, privé, congréganiste…). Les doublons (même nom, même commune) sont ignorés.
